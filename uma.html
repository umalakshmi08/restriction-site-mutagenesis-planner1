Restriction Site Mutagenesis Planner

Enter a DNA sequence and pick an enzyme. The planner finds the cut site and proposes a single-base change that removes it.

ATGCGTGAATTCCGATGGATCCATGC

EcoRI recognition site at position 7

The problem

Restriction enzymes cut DNA at short, specific sequences called recognition sites. EcoRI, for example, cuts at GAATTC. In cloning experiments you sometimes need an enzyme to leave a particular site alone.

One way is a point mutation: change a single base inside the site and the enzyme no longer recognises it. This project automates finding that site and planning the change.

Validate

Accept a DNA sequence and reject anything that isn't A, T, G or C.

Describe

Report the length, GC content and reverse complement.

Locate

Find every occurrence of the chosen enzyme's site.

Mutate

Propose a one-base change that destroys the site and show the new sequence.

Supported enzymes

A restriction enzyme recognises a short palindromic sequence and cuts there. A point mutation inside that sequence means the enzyme no longer recognises it.

EnzymeRecognition site
EcoRIGAATTC
BamHIGGATCC
HindIIIAAGCTT

How it works

  1. Enzyme dictionary

    A dictionary maps each enzyme name to its recognition sequence.

  2. Input and validation

    The sequence is uppercased and stripped of spaces. It is rejected if it is empty or contains anything other than A, T, G or C.

  3. Sequence properties

    Prints the length, GC percentage (rounded to 2 decimals) and the reverse complement using Biopython.

  4. Enzyme selection

    If the enzyme name isn't in the dictionary, the program prints "Invalid enzyme".

  5. Site search

    A window the length of the site slides along the sequence and collects every start position that matches. Positions are shown 1-based.

  6. Mutation search

    For the first site found, it tries the other three bases at each position inside the site and checks whether the site is now different.

  7. Output

    The first disrupting mutation is printed with its position, the mutated DNA and "Selected site disrupted".

Project update 2: first planner

mutagenesis_planner.py 
# Restriction Site Mutagenesis Planner

sites = {"EcoRI": "GAATTC", "BamHI": "GGATCC", "HindIII": "AAGCTT"}

dna = input("DNA sequence: ").upper()
enzyme = input("Enzyme (EcoRI/BamHI/HindIII): ")

if set(dna) - set("ATGC"):
    print("Invalid DNA sequence")
elif enzyme not in sites:
    print("Invalid enzyme")
elif sites[enzyme] not in dna:
    print("Restriction site not found")
else:
    site = sites[enzyme]
    pos = dna.find(site)
    new = dna[:pos] + "C" + dna[pos + 1:]

    print("Original:", dna)
    print("Mutated: ", new)
    print("Position:", pos + 1)

    if site not in new:
        print("Restriction site removed")
    else:
        print("Restriction site still present")

Project update 4: final version

Adds Biopython for GC content and reverse complement. Install it with conda install biopython -c conda-forge.

project update 4 final code.py 
from Bio.Seq import Seq
from Bio.SeqUtils import gc_fraction

enzymes = {"EcoRI": "GAATTC", "BamHI": "GGATCC", "HindIII": "AAGCTT"}
dna = input("DNA sequence: ").upper().strip()

if not dna or any(b not in "ATGC" for b in dna):
    print("Invalid DNA sequence")
else:
    print("Length:", len(dna), "GC%:", round(gc_fraction(Seq(dna))*100, 2))
    print("Reverse complement:", Seq(dna).reverse_complement())
    enzyme = input("Enzyme (EcoRI/BamHI/HindIII): ").strip()

    if enzyme not in enzymes:
        print("Invalid enzyme")
    else:
        site = enzymes[enzyme]
        positions = [i for i in range(len(dna)-len(site)+1) if dna[i:i+len(site)] == site]
        print("Site positions:", [p+1 for p in positions])

        if not positions:
            print("Restriction site not found")
        else:
            pos = positions[0]
            for i in range(pos, pos+len(site)):
                for base in "ATGC":
                    if base != dna[i]:
                        new = dna[:i] + base + dna[i+1:]
                        if new[pos:pos+len(site)] != site:
                            print("Mutation:", dna[i], "->", base, "at", i+1)
                            print("Mutated DNA:", new)
                            print("Selected site disrupted")
                            break
                else:
                    continue
                break

Limitations

  • It doesn't check whether the mutation is silent, so it may change an amino acid if the site is in a coding region.
  • It mutates only the first occurrence. Other copies of the site remain.
  • It proposes the first valid mutation, not the best one, and lists no alternatives.
  • Only the forward strand is searched, and only three enzymes are included.

What's next

  • Translate the sequence with Seq.translate() and accept only silent mutations that leave the protein unchanged.
  • Show all possible mutations and let the user choose one.
  • Add more enzymes (XhoI, PstI, KpnI) and search the reverse complement strand.
  • Build a simple web interface for input and output.

Conclusion

The project combines core Python (dictionaries, loops, slicing, conditions) with Biopython to automate a real molecular biology task: finding a restriction site and planning a point mutation that removes it. The program validates its input, handles error cases and gives clear output.
